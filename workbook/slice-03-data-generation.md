# Slice 03 - Synthetic Data Generation

## Purpose

Generate reproducible training data using operational rules, not random rows.

## Files

- `config/generation_rules.json`
- `backend/generator.py`
- `scripts/generate_sample_data.py`

## Done Means

- Script generates routes, stops, trips, and stop events.
- Outputs are saved in `data/generated/`.
- Student can explain the role of Seed, peak hours, and problem stop.
