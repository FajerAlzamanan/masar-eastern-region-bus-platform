# Slice 07 - Recommendation

## Purpose

Turn evidence into a reviewable recommendation.

## Files

- `backend/recommendation.py`
- `config/decision_card.json`
- `data/outputs/recommendation.json`

## Done Means

- Recommendation includes action, target stop, expected improvement, confidence, limitations, and next step.
- Recommendation is blocked if quality fails.
- Student can present the logic without hiding assumptions.
