# Slice 01 - Project Overview

## Purpose

Define the project before building screens. The page should answer: what is the problem, who decides, and what evidence will support the decision?

## Files

- `config/problem_scope.json`
- `config/roles.json`
- `config/decision_card.json`
- `frontend/src/App.jsx`

## Done Means

- Overview page displays problem, decision owner, decision, and scope.
- Student can explain why the project is not just a dashboard.
- Evidence screenshot is saved.
