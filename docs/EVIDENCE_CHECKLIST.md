# Evidence Checklist

Each completed task should include:

- Screenshot of the page or output.
- Changed file list.
- Test output.
- Generated CSV or JSON output when relevant.
- Short explanation of what changed.
- What decision or product slice the task supports.
- Known limitation.
- Commit link when using GitHub.

## Evidence Examples

For `generation_rules.json`:

- Screenshot of Data Lab.
- Exported generated CSV.
- Explanation of the changed rule.

For `validation.py`:

- Test output.
- Validation report JSON.
- Screenshot of Data Quality page.

For `recommendation.py`:

- Recommendation JSON.
- Screenshot of Recommendation page.
- Explanation of evidence, confidence, and limitations.
